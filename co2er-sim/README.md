# co2er-sim
A parameterised electrochemical steady-state reactor model that predicts CO₂ to CO conversion, product yield, 
hydrogen by-product, and energy consumption as a function of operating conditions such as voltage, feed composition, 
catalyst parameters, and cell geometry. The model combines simplified reaction kinetics, mass transport constraints, 
and electrical energy balances in a modular Python codebase with tests and documentation.

## Motivation
Electrochemical CO₂ reduction to CO is an important reaction for sustainable fuels and chemical feedstocks. However, 
common difficulties include competing reactions, high capital expenditure (CAPEX), high operating expenditure (OPEX),
and mass transport limitations. This model aims to provide a modular Python framework to simulate reactor performance
under varying catalysts, electrolytes, temperature, and pressure.

## Planned Features
- Steady-state CO₂ → CO modelling
- Butler–Volmer kinetics
- Configurable catalysts and electrolytes
- Modular Python code
