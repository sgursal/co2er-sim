# Inputs
- Applied voltage
- CO2 concentration

# Outputs
- Current density
- CO production rate


# Assumptions
- Steady-state continuous operation
- No mass transport (initial)
- No competing HER reaction (initial)
- Alkaline electrolyte (initial)

# Reactions

- CO2 + H20 + 2e- → CO + 2OH-
- 4OH- → O2 + 2H20 + 4e-
